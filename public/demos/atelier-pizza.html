CÔTÉ RESTAURATEUR

Votre carte change.
Votre site suit.

Un nouveau prix, une pizza momentanément indisponible ou une fermeture exceptionnelle : modifiez les champs dans votre espace WordPress, puis enregistrez.

La présentation reste cohérente. Aucun code à modifier, aucune nouvelle mise en ligne à demander pour ces contenus.

Voir le principe d’édition Cet aperçu HTML permet de consulter et filtrer la carte. Les modifications réelles sont réservées au prototype WordPress local.
